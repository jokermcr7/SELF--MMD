# MMD SELF · Rebuild 1

نسخهٔ بازسازی‌شده از پایه با ساختار ساده و روشن. این نسخه عمداً یک هستهٔ اولیه است؛ قابلیت‌های قدیمی بدون بررسی به پروژهٔ جدید منتقل نشده‌اند.

## امکانات فعلی
- پنل فارسی با تصویر برند MMD SELF
- درخواست دسترسی کاربر و تأیید/رد توسط مدیر اصلی
- ورود حساب اختیاری با شماره، کد تلگرام و رمز دومرحله‌ای
- نرمال‌سازی شماره‌ها: +کد کشور، فاصله، خط تیره، پرانتز و ارقام فارسی/عربی
- رمزگذاری نشست‌های ذخیره‌شده با Fernet
- وضعیت اتصال و توضیحات حریم خصوصی
- پیکربندی Railway با Dockerfile و متغیرهای محیطی

## متغیرهای محیطی لازم
`BOT_TOKEN`, `OWNER_ID`, `TG_API_ID`, `TG_API_HASH`, `SESSION_SECRET`. `DB_PATH` پیش‌فرض `/data/mmd_self.db` است.

برای تولید کلید رمزگذاری Fernet، در محیط پایتون اجرا کن:
```python
from cryptography.fernet import Fernet
print(Fernet.generate_key().decode())
```

کلید `SESSION_SECRET` را محرمانه و ثابت نگه دار. اگر تغییر کند، نشست‌های قبلی قابل رمزگشایی نخواهند بود. در Railway برای `/data` باید Volume پایدار وصل کنی؛ بدون volume ممکن است SQLite پس از redeploy از دست برود.

## دیپلوی
1. محتویات همین پوشه را در ریشهٔ مخزن GitHub قرار بده؛ ZIP را به‌عنوان فایل پروژه آپلود نکن.
2. متغیرهای محیطی را در Railway تنظیم کن.
3. اگر از SQLite استفاده می‌کنی، Volume را روی `/data` متصل کن.
4. Deploy کن و لاگ شروع را بررسی کن.

## نکات امنیتی مهم
- فقط حسابی را متصل کن که مالک آن هستی یا اجازهٔ صریح داری.
- کد ورود و رمز دومرحله‌ای را با هیچ فرد دیگری به اشتراک نگذار.
- هرگز `BOT_TOKEN`، `TG_API_HASH` یا `SESSION_SECRET` را در GitHub قرار نده.
- برای ابطال نشست، از Telegram → Settings → Devices استفاده کن.
- این نسخه پایه است؛ هنوز آزمون زنده با حساب تلگرام/Railway انجام نشده و قبل از انتشار عمومی باید تست بار، خطاهای ورود و بازیابی نشست اضافه شود.
