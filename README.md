# پنل حرفه‌ای سلف تلگرام

## مسیر ورود اجباری
1. کاربر `/start` می‌زند؛ هیچ شماره‌ای در مرحله اول گرفته نمی‌شود.
2. درخواست دسترسی برای مدیر ارسال می‌شود.
3. مدیر «تأیید دسترسی» را می‌زند.
4. فقط بعد از تأیید، شماره اکانت به‌صورت اجباری و دستی از کاربر گرفته می‌شود.
5. کاربر «ارسال کد ورود» را می‌زند.
6. کد با صفحه کلید عددی وارد می‌شود و با «تأیید کد» نهایی می‌شود.
7. اگر تأیید دومرحله‌ای فعال باشد، رمز در مرحله جداگانه از خود کاربر گرفته می‌شود.
8. بعد از ورود موفق، پنل فارسی کامل باز می‌شود.

## امنیت
- شماره به شکل ماسک‌شده در پیام مدیر نمایش داده می‌شود.
- نشست Telethon با Fernet رمزنگاری و در دیتابیس ذخیره می‌شود.
- کد ورود و رمز دومرحله‌ای را برای هیچ شخصی ارسال نکنید.
- `TG_API_ID`، `TG_API_HASH` و `SESSION_SECRET` را فقط در متغیرهای محیطی Railway قرار دهید.

## رابط کاربری
- منوی اصلی کاملاً فارسی است.
- هر بخش دکمه «راهنمای این بخش» دارد.
- صفحه کد دارای کلیدهای عددی، پاک‌کردن، حذف رقم، تأیید و راهنماست.
- فونت‌های متعدد برای ساعت زنده پروفایل وجود دارد.

## Railway
متغیرهای لازم:
- `BOT_TOKEN`
- `OWNER_ID`
- `DATABASE_URL`
- `DEFAULT_TIMEZONE`
- `TG_API_ID`
- `TG_API_HASH`
- `SESSION_SECRET`
