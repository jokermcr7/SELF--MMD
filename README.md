# Telegram Self Manager — Clean Diamond Edition

این نسخه عمداً از صفر خلوت شده است.

## فقط این‌ها فعال هستند
- ورود سلف و مدیریت نشست ورود
- باز کردن پنل با `پنل`، `.پنل` و `/پنل` در همان چت
- 🔴💎 کیف پول و مدیریت الماس
- شارژ/کسر الماس توسط مدیر
- انتقال الماس با ID، username یا reply
- جستجوی کاربران برای عملیات الماس
- تاریخچه تراکنش‌ها
- آمار الماس
- تنظیم نرخ مصرف و پارامترهای الماس
- فعال/غیرفعال شدن سلف بر اساس موجودی الماس موجود

## عمداً حذف شده
تمام قابلیت‌های قبلی سلف، منوها و دکمه‌های مربوط به ساعت، پروفایل، ریکت، اتوماسیون، پاسخ خودکار، فیلتر، بازی، ترجمه، گوگل، انیمیشن، کامنت، رسانه، حفاظت اسم، ابزارها، بکاپ و غیره از رابط و handlerهای اجرایی این نسخه حذف شده‌اند.

ورود سلف دست‌نخورده نگه داشته شده تا از خراب شدن مسیر login جلوگیری شود.

## متغیرهای محیطی
`BOT_TOKEN`, `OWNER_ID`, `DATABASE_URL`, `DEFAULT_TIMEZONE`, `TG_API_ID`, `TG_API_HASH`, `SESSION_SECRET`
