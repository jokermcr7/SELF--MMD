# Telegram Self Manager — Film Features Update

## این نسخه چه چیزی را درست می‌کند؟
- مدیریت کامل کاربران برای مدیر: فهرست، جستجو با ID/@username/نام، اطلاعات کامل، تأیید، رفع مسدودی، مسدودی، حذف نشست سلف و مشاهده جزئیات.
- مدیریت کامل الماس: فهرست، جستجو، شارژ/کسر سریع، مقدار دلخواه، صفر کردن موجودی، تاریخچه تراکنش‌ها، موجودی بعد از هر تراکنش و ثبت عامل/یادداشت.
- میانبر `پنل`، `.پنل` و `/پنل` پنل را در همان چتی که پیام ارسال شده باز می‌کند.
- ورود سلف دست‌کاری نشده است.

## نکته مهم برای گروه‌ها
برای اینکه `.پنل` به‌عنوان متن معمولی در گروه‌ها دریافت شود، در BotFather بخش Group Privacy را برای ربات خاموش کن (Privacy Mode = OFF). بعد از آن ربات می‌تواند متن `.پنل` را در همان چت دریافت و پاسخ دهد.

## متغیرهای محیطی
- `BOT_TOKEN`
- `OWNER_ID`
- `DATABASE_URL`
- `DEFAULT_TIMEZONE`
- `TG_API_ID`
- `TG_API_HASH`
- `SESSION_SECRET`

هیچ کد ورود تلگرام، رمز دومرحله‌ای، API Hash یا Session Secret را برای کسی ارسال نکن.
